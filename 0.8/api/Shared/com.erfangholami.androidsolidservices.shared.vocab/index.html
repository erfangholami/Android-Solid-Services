ShareNotificationVocabulary
Link copied to clipboard
interface ShareNotificationVocabulary

Legacy access-mode fallback literals a share-notification profile recognises when an incoming notification carries its mode as a string literal rather than the standard WAC acl:mode IRI. Lets the reader accept a namespace other than SolidShare's for these older notifications; new notifications always use acl:mode, so this only affects backward-compatible reads.

interface ShareVocabulary

The RDF vocabulary a sharing profile uses for its private given/received index and its public catalog. Lets the sharing engine be retargeted to a namespace other than SolidShare's without changing the index/catalog logic.

DataModulesBinder

class DataModulesBinder(contactsDataModule: SolidContactsDataModule, ticketsDataModule: SolidTicketsDataModule, guard: AccessGuard, moduleRoots: ModuleRootResolver, scope: CoroutineScope, dispatcher: CoroutineDispatcher = Dispatchers.IO) : IASSDataModulesService.Stub

The IASSDataModulesService binder, hosting the contacts and tickets module interfaces.

Each verb is checked on its module at VerbAccess.READ, VerbAccess.APPEND or VerbAccess.WRITE; a verb that takes an explicit container is checked on that container instead, so a module-scoped app cannot place a book or a ticket outside the module. A verb that can add a container tells moduleRoots to forget the account, so the next check sees it. There is no model translation: the IPC surface speaks the in-process types.

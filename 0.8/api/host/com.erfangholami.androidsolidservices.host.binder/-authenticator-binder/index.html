AuthenticatorBinder

class AuthenticatorBinder(session: HostSession, grants: AppGrantStore, guard: AccessGuard, scope: CoroutineScope, dispatcher: CoroutineDispatcher = Dispatchers.IO, readyTimeoutMillis: Long = DEFAULT_READY_TIMEOUT_MILLIS) : IASSAuthenticatorService.Stub

The IASSAuthenticatorService binder: sign-in state, the calling app's own grant, and revocation of that grant by the app itself.

The two synchronous verbs block the binder thread for one local read each: hasLoggedIn waits for the account store to load, bounded by readyTimeoutMillis; isAppAuthorized reads the grant store. Neither touches the network.

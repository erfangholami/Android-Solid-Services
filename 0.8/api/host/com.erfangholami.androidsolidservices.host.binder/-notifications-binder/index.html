NotificationsBinder

class NotificationsBinder(notificationsManager: NotificationsManager, guard: AccessGuard, scope: CoroutineScope, dispatcher: CoroutineDispatcher = Dispatchers.IO) : IASSNotificationsService.Stub

The IASSNotificationsService binder. The inbox belongs to the account, so every verb is checked on the whole pod: reads at VerbAccess.INBOX_READ, deletions at VerbAccess.INBOX_WRITE, and anything that speaks to another inbox as the user, or records a decision, at VerbAccess.INBOX_SEND. The acting account is the first WebID each verb takes.

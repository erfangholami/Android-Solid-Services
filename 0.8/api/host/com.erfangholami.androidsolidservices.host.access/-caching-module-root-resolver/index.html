CachingModuleRootResolver

class CachingModuleRootResolver(delegate: ModuleRootResolver, ttlMillis: Long = DEFAULT_TTL_MILLIS, clock: () -> Long = System::currentTimeMillis) : ModuleRootResolver

Remembers a delegate's answers for ttlMillis, because resolving a module's containers reads the type index and a granted app calls many times a second. A container created through the data-module binder is announced with invalidate, so the next check sees it.

AuthorizeProtocol

object AuthorizeProtocol

The host's half of the SolidAuthorization Intent protocol.

A consent activity reads the request with requestFrom, lets the user decide, resolves what they approved into entries with entriesFor, and finishes with one of the three results. The SDK's AuthorizeWithSolid contract is the other half.

SolidSignInClient

class SolidSignInClient

Manages sign-in authorization between a third-party app and the host app.

Obtain an instance via Solid.getSignInClient. All operations require the host app, Solid Share, to be installed on the device; see Solid.isHostInstalled.

Typical flow:

  1. Call getAccount — null means the app holds no grant for that WebID yet.

  2. Launch AuthorizeWithSolid from your Activity to let the user grant access, optionally with an com.erfangholami.androidsolidservices.shared.model.grant.AccessRequest that says what the app needs.

  3. Use disconnectFromSolid to give the grant back when the user signs out.

Every operation is a suspend function that waits for the IPC binding, so there is no need to collect authServiceConnectionState before calling; the flow is there for UI that wants to show the connection.

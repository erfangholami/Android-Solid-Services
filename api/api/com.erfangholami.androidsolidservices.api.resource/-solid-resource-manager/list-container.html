listContainer

open suspend fun listContainer(webId: String, containerUri: String, enrichWithHead: Boolean = false): SolidResult<List<SolidSourceReference>>

Lists the resources directly contained in the container at containerUri.

This is a single GET: each SolidSourceReference is built from the container's own representation (which Solid servers SHOULD enrich with stat:size / dcterms:modified / rdf:type), so it avoids the 1-GET-plus-N-HEAD fan-out of heading every child. Pass enrichWithHead to additionally HEAD each child — bounded to a few concurrent requests — filling SolidSourceReference.headMetadata for servers that don't enrich the listing; leave it off (default) for the cheap single call.

Parameters

webId

The WebID of the authenticated user making the request.

containerUri

The container to list (trailing /).

enrichWithHead

When true, HEAD each child (bounded concurrency) for full metadata.

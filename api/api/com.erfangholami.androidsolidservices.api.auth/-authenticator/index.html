Authenticator

interface Authenticator

Manages OpenID Connect authentication with Solid pods on behalf of one or more users.

Each user is identified by their WebID. Multiple users can be signed in simultaneously; the "active" user is the one whose session is currently selected.

Obtain an instance via Authenticator.getInstance.

expiredProfilesFlow
Link copied to clipboard
abstract val expiredProfilesFlow: StateFlow<List<SolidAccount>>

Emits accounts that were signed in but whose session has terminally expired — the provider rejected the refresh token (e.g. invalid_grant after a server-side session timeout), so they no longer appear in loggedInProfilesFlow. Their local state is retained: signing in again with the same WebID restores the account in place. SolidAccount.sessionError carries the recorded reason, and SolidAccount.isAuthorized is false.

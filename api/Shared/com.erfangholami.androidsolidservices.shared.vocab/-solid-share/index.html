SolidShare

object SolidShare

The SolidShare vocabulary: terms the project mints because no published vocabulary has them.

Two domains are covered — the sharing pipeline (share records and the access literals carried on LDN inbox notifications) and the wallet (the parts of a ticket that schema.org cannot express). See documents/TICKET_VOCAB.md for the full ticket dictionary and the justification for each minted term; the short version is that schema.org has no barcode symbology, no scheduled-vs-actual time pair, no fare class, no venue timings, and no presentation model.

Terms are minted under NAMESPACE — solidshare.app, the domain the project owns and verifies, so the namespace IRI can dereference to the vocabulary it names.

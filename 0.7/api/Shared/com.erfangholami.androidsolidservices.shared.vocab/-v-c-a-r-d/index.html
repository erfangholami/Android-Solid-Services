VCARD

object VCARD

vCard Ontology vocabulary constants. http://www.w3.org/2006/vcard/ns#

Used by Solid pods to represent contacts, address books, and groups. The Solid Contacts data module stores vcard:Individual resources inside vcard:AddressBook containers, with membership expressed via HAS_MEMBER.
